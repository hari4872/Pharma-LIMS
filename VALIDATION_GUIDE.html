Sample Registration

▼
Open Sample Registration
Click Sample Registration in the Operations section of the sidebar.
✅ Expect: Table of existing samples. Status filter dropdown. Register Sample button top-right.
Register a new sample
Click Register Sample. Fill in: Material (pick any), Lot Number = LOT-TEST-001, Sample Type, Due Date = tomorrow's date. Submit.

⚠ If no "Sign SRF" button: ensure sample status is Registered and your role is Admin/QA.

▼
Open SPC / Trending
Click SPC / Trending in the sidebar.
✅ Expect: Parameter dropdown, Points selector (20/50/100/200). KPI cards area. Chart area shows placeholder until parameter selected.
Load a control chart
Select any parameter from the dropdown. Click Load Chart.

Batch Release 21 CFR 211.192
0/4 steps
▼
Open Batch Release
Click Batch Release in the sidebar.
✅ Expect: Table with Status filter. Columns: Sample, Material/Lot, Status, Decision, Initiated By, Reviewed By, Date. View Checklist + Make Decision buttons.
Initiate a batch review
Click Initiate Review. If no samples appear, first ensure a sample has status PendingQAReview. Select the sample. Click Initiate Review.
✅ Expect: New batch release record created with status InReview. 5-item compliance checklist auto-evaluated.
⚠ If "No samples in PendingQAReview": go to Results Review and approve a sample first to move it to PendingQAReview status.
View checklist
Click View Checklist on the new batch release record.
✅ Expect: 5 checklist items with ✅ or ❌: All Tests Complete, No Open OOS, CoA Approved, No Open CAPA, Logbook Signed. Any failures show amber warning — QA can still proceed with documented justification.
Make a release decision
Click Make Decision. Select Released. Enter reason: All checklist criteria met — batch approved for distribution. Enter password Admin@123, Meaning = QA Batch Release Decision, Reason = Full review complete. Submit.
✅ Expect: Batch status → Released. Decision badge turns green. Sample status → Released. §11.50 e-signature permanently recorded in audit log.
